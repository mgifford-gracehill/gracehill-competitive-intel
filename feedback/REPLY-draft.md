## What would actually help, and how to keep it small

Please don't send everything. What the system needs isn't more documents — it's the layer above
them. For each content area, three things:

1. **The claim** — one sentence, the thing that is true.
2. **The nuance** — the two or three things an outsider would get wrong, in your words.
3. **A primary source** we can point at, if one exists. "No public source, ask me" is a valid answer
   and more useful than a guess.

Start with two areas rather than all of them, and let's see whether the output changes the way we
both expect it to. If it does, we scale the format. Your six statements are already in exactly
this shape — that's the template.

The other thing I'd like from you: **an owner per content area.** The 20 unsourced product records
need a name against them more than they need a document.
